# Мелюр · Брянск

Демонстрационная версия сайта клиники на основе ветки `template`.

- [Демо на GitHub Pages](https://gomzyakoffnickita.github.io/Clinic-prototype/meilleur/)
- [Официальный сайт клиники и источник материалов](https://meilleur-cosmetology.ru/)
- [Источник данных о команде](https://meilleur-cosmetology.ru/personal-kliniki)
- [Источник каталога](https://meilleur-cosmetology.ru/services)

`npm run dev` запускает локальный сервер. `npm run build` создаёт сборку для `/Clinic-prototype/meilleur/`.

`npm run deploy` обновляет подпапку `meilleur` в ветке `gh-pages`. GitHub Pages обслуживает её из корня ветки публикации.

Для возврата к шаблону используйте `git switch template`. Для возврата к исходной версии EK Clinic используйте `git switch main`.
